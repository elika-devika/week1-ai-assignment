# Week 1 AI Assignment

## Objective

This repository contains the Week 1 AI Assignment demonstrating Git, GitHub, Python programming, and API integration.

## Repository Structure

week1-ai-assignment/

├── README.md

├── main.py

├── api_task.py

├── report.pdf

├── screenshots/

│   ├── api_output.png

│   └── project_output.png

└── assets/

## Files Description

### main.py

A simple Python program that accepts user input and displays a greeting message.

### api_task.py

A Python script that fetches data from GitHub's public API and displays information from the response.

### report.pdf

Contains the assignment report and documentation.

### screenshots

Contains screenshots of the output generated by the Python programs.

## Technologies Used

- Python
- Git
- GitHub
- REST API
